🚀 DevOps Commands Reference

🌍 1. Terraform (Infrastructure as Code)

Core commands to provision and manage infrastructure on AWS:

# Initialize the working directory (Downloads required plugins/providers)
terraform init

# Preview changes (Shows exactly what resources will be created/modified)
terraform plan

# Deploy infrastructure (Provisions the resources on AWS)
terraform apply -auto-approve

# Delete infrastructure (Destroys all provisioned resources to avoid costs)
terraform destroy -auto-approve

⚙️ 2. ArgoCD (GitOps Deployment)

Commands to manage declarative GitOps pipelines and sync applications:

# Deploy the Master/Root Application (App-of-Apps pattern)
kubectl apply -f root-app/root-application.yaml -n argocd

# Check the sync and health status of all ArgoCD applications
argocd app list

# Force a manual sync (Useful if GitHub webhooks are not yet configured)
argocd app sync root-master-application

🔍 3. Kubernetes & Debugging

Essential commands to troubleshoot errors and inspect cluster resources:

# List all pods in a specific namespace
kubectl get pods -n <namespace>

# Fetch the logs of a specific pod to identify application errors
kubectl logs <pod-name> -n <namespace>

# Inspect detailed pod events (Crucial for diagnosing CrashLoopBackOff or OOMKilled)
kubectl describe pod <pod-name> -n <namespace>
